# Deploy — evolvo-web

## Vercel project
- Name: `evolvo-web`
- GitHub: https://github.com/ubaid-dev-01/evolvo-web

## CLI
```bash
cd evolvo-web
vercel --prod --yes
```

## Pipeline
1. Native Git: `vercel git connect https://github.com/ubaid-dev-01/evolvo-web.git`
2. GitHub Actions: set secrets `VERCEL_TOKEN`, `VERCEL_ORG_ID`, `VERCEL_PROJECT_ID`
